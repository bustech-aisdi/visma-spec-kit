# Visma Specifications Kit

This repository contains specifications and guidelines for various Visma teams.

## GitHub Pages

This repository is configured with GitHub Pages to display HTML specifications directly in the browser.

**Live site:** `https://[your-username].github.io/visma-spec-kit/`

## Structure

- Each specification should be in its own folder
- HTML presentations can be viewed directly via GitHub Pages
- Use the `index.html` as the main landing page

## Adding New Specifications

1. Create a new folder for your specification
2. Add your HTML files, markdown, or other assets
3. Update the main `index.html` to link to your specification
4. Commit and push - GitHub Pages will automatically deploy
