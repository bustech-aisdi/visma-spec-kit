Presentation Guidelines

Standards for creating effective presentations at Visma

📋 Template Structure

Every presentation should follow this basic structure:

Slide 1: Title & Objectives

  • Clear, descriptive title
  • Presenter name and role
  • Date and audience
  • Key objectives listed

Slide 2: Problem Statement

  • What problem are we solving?
  • Why is this important?
  • Impact on business/users
  • Current state vs desired state

Slide 3: Proposed Solution

  • High-level solution overview
  • Key benefits
  • Success metrics
  • Implementation timeline

Slide 4: Next Steps & Q&A

  • Clear action items
  • Timeline for implementation
  • Open floor for questions

💡 Best Practices

📊 Keep slides visual

Use minimal text with supporting visuals

🎨 Consistent branding

Use consistent colors and fonts throughout

⏱️ Practice timing

Aim for 15-20 minutes + Q&A

📝 Clear call-to-action

Include next steps and action items

💬 End with Q&A

Always allow time for questions

📱 Mobile-friendly

Ensure readability if sharing digitally
